### Encapsulation

As part of the Lexicon course, this week we're working on Object Oriented Programming (OOP).

This particular assignment is focusing on encapsulation and includes private fields, a constructor for the Person-class, and getters and setters.
Error handling with exceptions are included, which alerts the user if invalid names, age, or salary is entered.

## Key Takeaways
Working on OOP-fundamentals is great for me as it builds a solid foundation which we'll build upon later in the course for fullstack development,
I found it especially good to practice using the 'this' keyword, utilizing 'getters' and 'setters' and making the distinction between fields and properties.
